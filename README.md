# UART-Controller-with-FSM-Based-Transmitter-and-Receiver-using-systemverilog
Designed and verified a UART (Universal Asynchronous Receiver Transmitter) Controller using SystemVerilog for asynchronous serial communication. Implemented separate Transmitter (TX) and Receiver (RX) modules using Finite State Machine (FSM) architecture. Simulated and verified the design in Xilinx Vivado

# Overview

This project focuses on the design and verification of a UART Controller, a widely used communication protocol in embedded and digital systems. The controller enables serial data transfer between devices by converting parallel data into serial form during transmission and serial data back into parallel form during reception. FSM-based TX and RX modules were developed and tested through simulation to validate functionality and timing behavior.

# Key Features

UART Transmitter (TX) and Receiver (RX) design.

FSM-based architecture for control and data flow.

Asynchronous serial communication support.

Parallel-to-Serial and Serial-to-Parallel data conversion.

Start bit, stop bit, and data bit handling.

Functional verification through simulation.

RTL design and waveform analysis in Vivado.


# Tools & Technologies

Hardware Description Language: SystemVerilog

Simulation & Verification: Xilinx Vivado Simulator

Design Methodology: RTL Design

Architecture: Finite State Machine (FSM)

Communication Protocol: UART
